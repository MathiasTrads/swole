# Swole

Mathias' Muay Thai coach as a home-screen web app (PWA).

- App: GitHub Pages from this repo. No personal data lives here.
- Data: private repo `swole-data` (`data/checkins.json`, `sessions.json`, `tests.json`, `settings.json`). The app writes there with a token that is stored only on the phone.
- Reminder: `.github/workflows/remind.yml` sends a push at 06:05 Copenhagen time with today's sessions.
